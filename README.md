# Python Micro OS

Pythonで作った、レトロPC風のマイクロOSプロジェクトです。

黒い画面、緑色の文字、起動時のMEMORY TEST――  
昔のコンピュータの“ロマン”を、Pythonで再現してみました。

## Features

- 起動演出（BOOT SEQUENCE）
- MEMORY R/W TEST 表示
- アセンブラ風コマンド入力
- REBOOT演出
- レトロPC風CLI画面
- HELP / DIR などの簡易コマンド
- 緑文字ターミナルUI
